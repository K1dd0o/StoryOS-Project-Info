# Security

This repository is informational only.

It must never contain:

- `.env` files;
- Reddit client IDs or client secrets;
- OAuth access or refresh tokens;
- database passwords;
- API keys;
- production database exports;
- private StoryOS source code;
- generated source-story datasets;
- private user information.

If a secret is accidentally committed, revoke/rotate it immediately and remove it from repository history.
